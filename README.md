<h1>BTC Mining Dashboard - StartOS 0.3.5.1</h1>
<h3>Real-time Bitcoin mining dashboard for pool miners and renting hash.</h3>

<b>Features</b>

<li>✅ Web-based dashboard - Live network data — hashrate, difficulty, block time</li>

<li>✅ Difficulty adjustment forecast — projected % change, epoch progress, ETA</li>

<li>✅ OCEAN pool stats — pool hashrate, blocks/day, network share, last block</li>

<li>✅ Hashprice index — live USD/PH/day and USD/TH/day calculated from network data</li>

<li>✅ BIP-110 signaling — live miner signaling tracker for the current epoch</li>

<li>✅ Bitcoin Knots — node distribution panel</li>

<li>✅ Profitability calculator — for hashrate, rental cost, BTC price, pool fee</li>

<li>✅ My OCEAN Stats — links to your miner dashboard, worker stats, and payout history</li>

<li>✅ Platform ready - Optimized for StartOS server deployments</li>

<h3>For Users</h3>

<b>Quick Start</b>

<li>Install via StartOS sideload the .s9pk package</li>
<li>Start service</li>
<li>Launch the web UI</li>

<h4>Currently supported:</h4>

<li>✅ x86_64 (Intel/AMD 64-bit)</li>
