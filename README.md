BTC Mining Dashboard - StartOS 0.3.5.1

A real-time Bitcoin mining dashboard for pool miners and renting hash.

Features

✅ Web-based dashboard - Live network data — hashrate, difficulty, block time 
✅ Difficulty adjustment forecast — projected % change, epoch progress, ETA
✅ OCEAN pool stats — pool hashrate, blocks/day, network share, last block
✅ Hashprice index — live USD/PH/day and USD/TH/day calculated from network data
✅ BIP-110 signaling — live miner signaling tracker for the current epoch
✅ Bitcoin Knots — node distribution panel
✅ Profitability calculator — for hashrate, rental cost, BTC price, pool fee
✅ My OCEAN Stats — links to your miner dashboard, worker stats, and payout history
✅ Platform ready - Optimized for StartOS server deployments
